# KeyCast Studio · Brand 01

**입력이 장면이 되다.** 화면과 함께 단축키를 보여 주고, 클릭을 확대하며, 자막까지 편집하는 제품이다. 일반적인 빨간 녹화 원 대신 **K 키캡 + 재생 헤드**를 정체성으로 쓴다.

## 브랜드 자산

- 앱·설치 프로그램: build/icon.svg(원본), build/icon.png(512px), build/icon.ico(16/24/32/48/64/128/256px). 공개용 1024px PNG도 포함.
- 16–24px에서는 brand/icon-small.svg를 사용한다. 세부 테두리와 재생 헤드를 제거하고 K와 파란 선을 남긴다. 그 이상에서는 기본 아이콘을 쓴다.
- 문서·README·발표: 어두운 면은 brand/wordmark-dark.svg, 밝은 면은 brand/wordmark-light.svg. 흑백 인쇄용은 mark-monochrome.svg(기본 검정, SVG 내부의 currentColor로 조정). SVG 워드마크 글자는 편집 가능하며 시스템 글꼴을 사용한다.
- 가로 조합은 심볼과 이름 사이에 심볼 폭의 약 1/6, 바깥은 1/4 이상 비운다. 비율 변형, 그림자 추가, 빨간색으로 아이콘 바꾸기는 피한다.

## 기본 토큰

기존 v2.9.1의 그래파이트 색 체계를 CSS 변수 파일(src/brand/tokens.css)로 분리했다. 앱과 시작 화면이 같은 토큰을 쓴다. 타임라인·키 오버레이 예시는 디자인 보드에 분리되어 있고 기존 편집 기능은 바꾸지 않는다.

| 역할 | 값 | 사용 규칙 |
| --- | --- | --- |
| Depth / Background | #0F0F10 / #141415 | 앱 외곽 / 작업 배경 |
| Surface / Raised | #19191B / #232325 | 패널 / 눌러 보는 표면 |
| Text / Secondary | #EDEDED / #A1A1A6 | 기본 / 보조 설명 |
| Focus | #5B9DFF | 키보드 포커스, 선택, 재생 위치 |
| Record | #FF453A | 녹화 시작 및 실제 녹화 상태. 로딩에는 사용하지 않음 |
| Success / Warning / Danger | #4CC38A / #E3B341 / #E5484D | 완료 / 주의 / 오류. 상태는 색과 텍스트를 함께 사용 |

4px 단위 정렬. 키 배지 5px, 버튼 8px, 카드 14px, 패널 18px. 메타 12px, 보조 13px, 본문 14px, 패널 제목 16px, 화면 제목 20px. 시간 코드·단축키는 고정폭, 플랫폼별 시스템 글꼴 우선. 주요 대비: 텍스트/패널 15.0:1, 보조 텍스트/패널 6.82:1, 포커스/패널 6.45:1, 녹화 버튼 글자/배경 5.62:1.

## 구성요소

| 구성 | 기본 | 조작/상태 |
| --- | --- | --- |
| 버튼 | 중립은 Raised, 주요 실행은 밝은 버튼 | 2px 파란 포커스 링. 비활성은 명도만 낮추고 동작 차단 |
| 녹화 | 시작은 빨간 버튼, 글자는 #0F0F10 | 진행 중에는 빨간 점과 ‘녹화 중’ 동시 표기. 빈 화면이나 부팅에는 빨간 점 없음 |
| 키 오버레이 | Ctrl, Shift, K 같은 키캡의 기준선과 높이 통일 | OS에 맞는 키 명칭 사용. 사용자 오버레이 테마는 별도 유지 |
| 편집 타임라인 | 고정폭 시간 코드, 눈금, 영상·줌·자막을 별도 레인에 배치 | 파란 재생 헤드·선택 테두리. 배경보다 영상 내용 우선 |

## 시작 화면과 모션

- 창 내부 첫 화면. 자산이 로드되기 전부터 HTML에 로고가 있다. Electron이 창을 열기 전이나 포터블 EXE 압축 해제 중에는 표시되지 않는다.
- 키캡은 420ms에 9px 내려와 멈춘다. 180ms 뒤 재생 헤드가 한 번 이동한다. 글자·배경은 고정. 모든 모션은 같은 곡선(cubic-bezier(.22,1,.36,1)), 반동·반복 없음.
- 실제 홈 준비가 끝나면 지연 없이 150ms 페이드. 가짜 %나 의도적 최소 대기 없음. 실패 또는 15초 미응답 시 재시도 표시. 홈이 늦게라도 준비되면 즉시 표시한다.
- OS 모션 줄이기에서는 움직임과 페이드를 끈다. 시작 중에는 홈 조작을 잠그고, 상태를 보조기기에 알린다. 한국어 포함 12개 앱 지원 언어 문구 포함.
