KeyCast Studio 사용설명서

화면을 녹화하면서 누른 키와 클릭을 영상에 보여 주고, 원하면 목소리를 받아 적어 자막까지 넣어 주는 프로그램입니다.

목차
  1. 실행하는 방법
  2. 녹화하기
  3. 편집하기 (화면·자르기·줌·주석·키·커서·웹캠·소리)
  4. 음성 자막 만들기
  5. 영상 저장하기
  6. 단축키 모음
  7. 자주 묻는 질문

1. 실행하는 방법

데스크톱 앱 (추천)

  1. GitHub 릴리즈 페이지에서 KeyCast-Studio-Setup-x.y.z.exe를 내려받아 실행합니다.
  2. 설치할 폴더를 고르고 설치를 누릅니다. 커서 숨김 녹화에 쓰는 FFmpeg까지 함께 설치됩니다.
  3. 바탕화면이나 시작 메뉴의 KeyCast Studio로 실행합니다. 지울 때는 Windows 설정 › 앱에서 제거하세요. 녹화한 영상은 지워지지 않습니다.
설치하지 않고 쓰기: KeyCast-Studio-Portable-x.y.z.exe 파일 하나를 내려받아 바로 실행하세요. FFmpeg도 들어 있습니다. 실행할 때마다 먼저 풀어서 여는 데 몇 초 더 걸립니다.
처음 실행할 때 Windows가 「Windows의 PC 보호」 창을 띄우면 「추가 정보」 → 「실행」을 누르세요. 코드 서명 인증서가 없는 프로그램이라 나오는 안내입니다.

실제 마우스 커서를 숨기고 녹화하려면

설치 파일이나 휴대용 exe로 받았다면 따로 할 일이 없습니다. 이 기능에 쓰는 무료 프로그램 FFmpeg가 함께 들어 있습니다. 소스 코드로 직접 빌드했다면 winget install Gyan.FFmpeg로 FFmpeg 8 이상을 설치하세요.

macOS와 Linux

macOS: 릴리즈에서 -mac-arm64.dmg(Apple 실리콘) 또는 -mac-x64.dmg(Intel)를 받아 앱을 응용 프로그램 폴더로 옮깁니다. 아직 Apple 공증 전이라 처음에는 앱을 오른쪽 클릭 → 열기로 실행하세요. 첫 화면의 권한 설정 열기를 눌러 손쉬운 사용(키 기록)과 화면 기록을 허용한 뒤 앱을 다시 엽니다. 커서 숨김 녹화에는 brew install ffmpeg가 필요합니다.

Linux: .AppImage에 실행 권한을 주어 실행하거나 .deb를 설치합니다. 키·클릭 기록과 커서 숨김 녹화는 X11 세션에서만 되고, 커서 숨김에는 sudo apt install ffmpeg가 필요합니다.

컴퓨터 소리 녹음은 Windows에서만 됩니다. 맥·리눅스판은 아직 자동 검사만 거친 베타입니다.

화면 언어

첫 화면 오른쪽 위 언어 메뉴에서 12개 언어 중 하나를 고릅니다(한국어, English, 日本語, 简体中文, 繁體中文, Español, Français, Deutsch, Italiano, Nederlands, Português (Brasil), Русский). 처음에는 Windows 언어를 따릅니다.

확장 기능

첫 화면 오른쪽 위 ⚙ 설정 → 🧩 확장 기능에서 확장 폴더를 열고, 켜고 끄고, 공식 확장 6종을 넣을 수 있습니다. ✏ 새 확장 만들기를 누르면 실시간 미리보기를 보며 배경·키 테마·커서·클릭 효과·자막 스타일을 직접 만들어 앱에 넣거나 JSON 파일로 내려받을 수 있습니다. 확장은 배경·키 테마·커서 묶음·클릭 효과·자막 스타일을 더합니다. 편집 화면의 각 탭에 확장 항목이 나타나고, 고르면 그 값이 프로젝트에 복사됩니다.

브라우저 버전

소스 코드에서 npm run build:web으로 만들 수 있습니다. 브라우저 버전은 그 탭 안에서 누른 키만 기록하고, 탭을 닫으면 녹화가 사라집니다. 다른 프로그램에서 누른 키까지 보여 주려면 데스크톱 앱을 쓰세요.

2. 녹화하기

  1. 어디를 녹화할까요?에서 전체 화면 또는 창을 고릅니다.
    전체 화면을 고르면 클릭한 곳 자동 확대와 클릭 효과까지 쓸 수 있습니다.
  2. 오른쪽에서 무엇을 녹화하나요?를 고릅니다. 한 번 고르면 아래 설정이 함께 정해집니다.
    목적정해지는 것
    튜토리얼타이핑까지 기록, 녹화 중 키 보기, 부드러운 커서, 3초 뒤 시작, 컴퓨터 소리 끔. 편집할 때 모든 키를 보여 줍니다.
    제품 데모단축키만 기록, 녹화 중 키 보기, 부드러운 커서, 3초 뒤 시작, 컴퓨터 소리 켬.
    그냥 녹화화면과 소리만. 키 표시·자동 확대·클릭 효과 없이 바로 시작합니다.
    그 아래 동그란 칩이 지금 설정입니다. 칩을 누르면 켜고 끄며, 마이크·웹캠 칩은 목록이 열립니다. 하나라도 바꾸면 "직접 고른 설정"이 됩니다.
    옵션설명
    마이크목소리를 녹음합니다. 자막을 만들려면 켜 두세요.
    컴퓨터 소리 함께 녹음유튜브·게임 소리 등 컴퓨터에서 나는 소리도 같이 녹음합니다.
    꾸미기 · 웹캠얼굴을 동그란 말풍선으로 영상 구석에 넣습니다.
    타이핑한 글자도 기록기본은 꺼짐입니다. 꺼 두면 혼자 입력한 글자·숫자·기호는 저장하지 않고 단축키와 Enter·방향키 같은 키만 남깁니다. 비밀번호 같은 입력이 녹화 파일에 남지 않습니다. 타이핑도 영상에 보여 주려면 켜세요.
    녹화 중 화면에 키 보여주기녹화하는 동안 누른 키를 화면 아래에 띄웁니다. 나에게만 보이고 녹화 파일에는 들어가지 않습니다(키는 편집할 때 영상에 넣습니다). 녹화 중에도 녹화 막대의 키보드 버튼이나 Alt + Shift + K로 켜고 끌 수 있습니다.
    실제 마우스 커서 숨기고 녹화화면을 커서 없이 찍고, 편집할 때 크고 부드러운 커서를 대신 그려 넣습니다. 전체 화면 녹화에서만 되고, FFmpeg를 찾을 수 있을 때만 이 옵션이 보입니다(설치 파일과 휴대용 exe에는 들어 있음).
    3초 카운트다운시작 전에 3, 2, 1을 셉니다.
  3. 빨간 녹화 시작 버튼을 누릅니다. KeyCast 창은 사라지고 화면 위쪽에 작은 녹화 막대가 생깁니다.
  4. 평소처럼 작업하고 말하면 됩니다. 단축키와 클릭이 기록됩니다.
  5. 끝나면 녹화 막대의 ■ 멈춤 또는 Alt + Shift + S를 누릅니다. 바로 편집 화면이 열립니다.
녹화 막대는 녹화 영상에 찍히지 않습니다. 잠깐 멈추려면 일시정지 버튼 또는 Alt + Shift + P, 화면 키 표시를 켜고 끄려면 키보드 버튼 또는 Alt + Shift + K를 누르세요. 비밀번호를 칠 때는 🔒 버튼 또는 Alt + Shift + L로 키 기록을 잠깐 멈추세요. 다시 누를 때까지 어떤 키도 저장하지 않고, 막대에 "키 기록 멈춤"이 노랗게 보입니다.

녹화 없이 키만 보여주기

발표나 화상 회의, 다른 녹화 프로그램을 쓸 때 누른 키와 클릭만 화면 위에 띄울 수 있습니다.

  1. 처음 화면 오른쪽 아래 키 표시 켜기를 누릅니다. 이때 띄운 키는 다른 녹화 프로그램과 화면 공유에도 보입니다.
  2. 끄려면 같은 버튼을 다시 누르거나 Alt + Shift + K를 누릅니다.
  3. 꾸미기에서 키 모양과 보여줄 키를 정합니다. 여기서 정한 모양은 새 녹화에도 쓰입니다. 켜져 있는 키 표시는 껐다 켜야 바뀝니다.

다른 프로그램으로 만든 영상 열기

처음 화면 위쪽 영상 파일 열기로 MP4·WebM 영상을 불러와 똑같이 편집할 수 있습니다. 원본 파일은 그대로 두고 사본으로 작업합니다. 불러온 영상에는 키와 클릭 기록이 없어서 키 표시와 자동 확대는 쓸 수 없습니다.

Recordly로 찍은 영상은 옆에 있는 .cursor.json 파일에서 커서 위치·클릭·커서 종류를 함께 가져옵니다. 커서를 다시 그리고 클릭한 곳 자동 확대도 만들어집니다.

3. 편집하기

가운데에 완성될 영상이 보이고, 아래에 타임라인, 오른쪽에 설정이 세 묶음(꾸미기 · 편집 · 소리·자막)으로 있습니다. 묶음을 누른 뒤 그 아래 작은 버튼으로 세부 항목을 고릅니다. 바꾼 내용은 자동으로 저장됩니다.

타임라인

  • 영상 줄: 파란 막대의 양 끝을 끌면 앞뒤를 잘라 낼 수 있습니다. 빨간 구간은 중간에서 잘라낸 부분입니다.
  • 속도 줄: 노란 블록이 빠르게 또는 느리게 재생되는 구간입니다.
  • 줌 줄: 보라색 블록이 확대 구간입니다.
  • 주석 줄: 분홍 블록이 글자·화살표 같은 주석이 나오는 시간입니다.
  • 소리 줄: 청록 블록이 추가한 배경 음악·효과음입니다.
  • 키 줄: 키를 누른 시점이 표시됩니다(노란색은 단축키).
  • 자막 줄: 초록 블록이 자막입니다.
  • 내용이 없는 줄은 숨겨져 있다가, 그 줄을 다루는 항목(예: 편집 → 줌)을 열면 나타납니다.
  • 블록은 끌어서 옮기고, 끝을 끌어 늘립니다. 줄의 빈 곳을 더블클릭하면 그 줄에 새 블록이 생깁니다.
  • 블록을 고른 뒤 Delete를 누르면 지워집니다. 잘못 바꿨으면 Ctrl + Z로 되돌립니다.

오른쪽 설정

꾸미기 → 화면 맨 위의 추천 스타일 카드를 누르면 배경·키 모양·커서·클릭 효과·자막 모양이 한 번에 바뀝니다(기본으로 되돌리기). 항목마다 자주 쓰는 설정만 먼저 보이고, 나머지는 자세히 ▾를 누르면 펼쳐집니다.

묶음 · 항목할 수 있는 것
꾸미기 · 화면영상 비율(16:9, 9:16 세로 쇼츠, 1:1 등), 배경 색, 배경 그림(기본 6종·내 그림·배경 그림 폴더), 배경 흐림, 여백, 모서리 둥글기, 그림자 세기, 화면 가장자리 잘라내기(크롭)
편집 · 자르기앞뒤 자르기, 중간 잘라내기, 속도 바꾸기(0.25×~4×)
편집 · 줌클릭한 곳 자동 확대 켜기/끄기, 확대 배율과 속도, 커서 따라가기, 클릭 기준으로 다시 만들기
편집 · 주석글자, 화살표, 네모, 그림 넣기, 보이면 안 되는 곳 흐리게 가리기

꾸미기 · 커서클릭 효과(물결·겹물결·빛 번짐·터짐, 크기·길이·진하기), 커서 주변 강조, 휠 표시, 커서 다시 그리기(커서 묶음 6종과 녹화된 커서 종류 따라가기, 크기, 움직임: 정확하게·빠릿하게·부드럽게·느긋하게·직접, 잔상, 클릭 반동과 속도, 기울기, 멈춰 있으면 숨기기)

중간 잘라내기와 속도 바꾸기

  1. 잘라낼 곳의 시작으로 이동한 뒤 자르기 탭의 여기서부터 잘라내기를 누르거나 S를 누릅니다.
  2. 영상 줄에 생긴 빨간 구간의 양 끝을 끌어 범위를 맞춥니다. 빨간 구간은 재생과 저장에서 건너뜁니다.
  3. 되살리려면 빨간 구간을 고르고 되살리기 또는 Delete를 누릅니다.
  4. 속도는 여기에 속도 구간 넣기로 노란 블록을 만든 뒤 배속을 고릅니다. 소리도 같은 속도로 재생됩니다.

주석 넣기

  1. 주석이 나올 시각으로 이동한 뒤 주석 탭에서 + 글자, + 화살표, + 네모, + 그림, + 가리기 중 하나를 누릅니다.
  2. 미리보기에서 주석을 끌어 자리를 옮깁니다. 크기·색·방향은 탭에서 바꿉니다.
  3. 나오는 시간은 타임라인 주석 줄의 분홍 블록을 끌어 맞춥니다.
가리기는 영상 틀 기준으로 자리가 고정됩니다. 화면이 확대되거나 움직이면 가린 위치가 따라가지 않으니, 가릴 구간에는 줌을 넣지 않는 편이 안전합니다.

커서 다시 그리기

커서 탭에서 켭니다. 실제 마우스 커서 숨기고 녹화로 찍은 영상은 자동으로 켜져 있고, 끄면 영상에 커서가 보이지 않습니다. 커서를 숨기지 않고 찍은 영상에서는 녹화된 커서 위에 겹쳐 그리므로, 부드럽게를 높이면 두 커서가 잠깐 떨어져 보일 수 있습니다.

여기서 정한 화면·키·커서 모양은 다음 녹화에도 그대로 쓰입니다.

4. 음성 자막 만들기

  1. 편집 화면 오른쪽에서 소리·자막 → 자막을 엽니다.
  2. 정확도를 고릅니다. 처음에는 보통을 추천합니다. 한국어를 더 정확하게 받아 적으려면 정확이나 가장 정확을 고르세요(더 오래 걸립니다).
  3. 말한 언어를 한국어로 둡니다.
  4. 음성으로 자막 만들기를 누릅니다.
처음 한 번은 음성 인식 모델을 인터넷에서 내려받습니다(40MB~600MB). 그다음부터는 바로 시작합니다. 목소리는 인터넷으로 보내지 않고 이 컴퓨터 안에서만 처리합니다.

다 만들어지면 자막이 문장 단위로 나뉘어 아래 목록에 나옵니다. 틀린 글자는 목록에서 바로 고치고, 시작·끝 시간 숫자도 바꿀 수 있습니다. 조용한 구간이나 "시청해 주셔서 감사합니다" 같은 잘못 들은 문장은 자동으로 걸러 냅니다.

자막 모양에서 스타일 7종(상자·테두리·노란 글씨·노래방·강조 팝·종이·미니멀), 위치(아래·가운데·위), 나타나는 방식, 글자 크기와 색을 정할 수 있습니다. 노래방과 강조 팝은 말하는 낱말을 강조합니다(낱말 시간은 문장 길이로 어림합니다). SRT 저장을 누르면 유튜브 등에 올릴 수 있는 자막 파일로도 저장됩니다.

5. 영상 저장하기

  1. 가장 빠른 길: 오른쪽 위 흰색 MP4로 저장을 누르면 묻지 않고 동영상 폴더에 지난번 설정(처음에는 1080p)으로 저장합니다. 끝나면 폴더에서 보기나 다른 설정으로 저장…을 고를 수 있습니다.
  2. 형식과 위치를 직접 고르려면 그 옆의 내보내기 설정…을 누르고 파일 형식(MP4 추천), 화질(1080p 추천), 초당 프레임(30/60)을 고릅니다.
  3. 자막을 영상에 넣기를 켜면 자막이 영상에 새겨지고, SRT 자막 파일도 저장을 켜면 자막 파일이 영상 옆에 함께 저장됩니다.
  4. 저장할 곳 고르기를 누르고 위치와 이름을 정합니다.
  5. 영상 길이만큼 시간이 걸립니다. 그동안 KeyCast 창을 닫지 마세요.
  6. 끝나면 폴더에서 보기로 저장된 파일을 바로 열 수 있습니다.

GIF로 저장하기

파일 형식에서 GIF를 고르면 크기(긴 쪽 480~1080), 초당 프레임(10~25), 계속 반복 재생 여부를 정할 수 있습니다. GIF는 소리가 없고 용량이 커서 30초 이하의 짧은 구간에 알맞습니다. 반복되는 GIF는 커서 탭의 끝날 때 처음 위치로 돌아가기를 켜면 매끄럽게 이어집니다.

원본 녹화는 동영상 › KeyCast Studio 폴더에 보관됩니다. 처음 화면의 녹화 폴더 열기로 열 수 있고, 최근 녹화에서 다시 편집할 수 있습니다.

7. 자주 묻는 질문

키가 영상에 안 나와요.

편집 화면 키 탭에서 영상에 키 보여주기가 켜져 있는지 보세요. 재생 줄의 키 표시 버튼이 켜져 있는지도 보세요. 기본인 단축키만에서는 일반 타이핑이 나오지 않고, 첫 화면에서 ⌨ 단축키만 기록 칩인 채로 녹화했다면 모든 키로 바꿔도 타이핑은 나오지 않습니다. 고른 키만이면 목록에 넣은 키로 시작하는 입력만 나옵니다. 한글 타이핑은 녹화할 때 한글 입력기가 한글 상태였으면 "안녕"처럼 한 글자씩 조합되어 보입니다(Windows). 예전 녹화나 맥·리눅스에서 녹화한 영상은 키 탭의 한글 입력을 항상 한글로 바꾸세요.

자동 확대가 안 돼요.

창을 골라 녹화하면 클릭 위치를 알 수 없어 자동 확대가 만들어지지 않습니다. 전체 화면으로 녹화하거나, 타임라인 줌 줄을 더블클릭해 직접 넣으세요.

영상에 커서가 안 보여요.

실제 마우스 커서 숨기고 녹화로 찍은 영상입니다. 편집 화면 커서 탭에서 커서 그리기를 켜세요. 실제 커서가 찍힌 영상을 원하면 첫 화면의 🖱 부드러운 커서 칩을 눌러 실제 커서로 바꾸고 녹화하세요.

「실제 마우스 커서 숨기고 녹화」 옵션이 안 보여요.

FFmpeg를 찾지 못한 경우입니다. 설치 파일로 다시 설치하거나, FFmpeg 8 이상을 설치하거나, ffmpeg.exe를 앱 폴더 안 resources › app › bin 폴더에 넣으면 나타납니다. 창을 골라 녹화할 때는 옵션이 켜져 있어도 실제 커서가 찍힙니다.

자막이 하나도 안 생겨요.

녹화할 때 마이크가 「사용 안 함」이었는지 확인하세요. 소리가 너무 작으면 말이 없는 것으로 판단할 수 있습니다. 정확도를 올려서 다시 만들어 보세요.

자막 만들기가 너무 느려요.

그래픽카드로 빠르게를 켜고, 정확도를 빠름이나 보통으로 낮춰 보세요.

녹화를 지우고 싶어요.

처음 화면 최근 녹화에서 해당 녹화의 삭제를 누르세요. 되돌릴 수 없습니다.
